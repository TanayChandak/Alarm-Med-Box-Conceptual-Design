## Project Overview

The Smart Medicine Box is a conceptual biomedical engineering design project focused on improving medication organization, accessibility, and adherence through an integrated storage and reminder system. The project combines CAD-based mechanical design with embedded electronics concepts to create a compact and user-friendly medication management device intended for individuals who require consistent medication schedules.

This project was developed using Onshape CAD software and incorporates multiple medication compartments, a hinged access system, and designated housing for Arduino-based electronic components and LED reminder indicators. The design emphasizes organization, usability, and future expandability for smart healthcare applications.

---

## Design Objectives

The primary objective of this project was to develop a conceptual medication storage system capable of assisting users with medication organization and scheduled reminders while maintaining a compact and manufacturable design. The project aimed to address common issues associated with medication adherence, including forgotten doses, disorganized storage, and limited accessibility.

Key design goals included:

* Creating a compartmentalized medication storage layout
* Integrating electronic reminder functionality
* Designing a compact and ergonomic enclosure
* Allowing space for embedded electronics and future sensors
* Developing a manufacturable and modular CAD assembly

## Features

* Multiple medication storage compartments
* Hinged lid mechanism for accessibility

## Engineering and Technical Considerations

Several engineering principles were considered throughout the design process, including:

* Mechanical assembly alignment and spacing
* Internal compartment optimization
* Accessibility and ergonomic interaction
* Space allocation for embedded hardware components
* Structural simplicity for manufacturability
* Expandability for future electronic integration

The design process also considered how embedded electronics could later be integrated to enable timed medication reminders, alarm systems, or sensor-based monitoring systems.
